# Ratan Ambhore — Personal Portfolio

A modern, responsive personal portfolio website created using **HTML5, CSS3 and JavaScript**.

## Features

- Responsive navigation with mobile hamburger menu
- Dedicated Internship page with 5 internship slots and project links
- Circular passport-style profile photo with blue glow
- Hero section with professional profile photo
- Animated typing effect
- About Me, Education and Learning Journey
- Skills with progress bars
- Project showcase with filtering
- Contact form with client-side validation
- Dark / Light mode with localStorage
- Scroll reveal animations
- Hover effects and smooth scrolling
- Back-to-top button
- Resume download button
- Font Awesome icons
- GitHub Pages ready

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Run Locally

Open `index.html` in a browser, or use VS Code Live Server.

## Before Deployment

1. Replace placeholder GitHub, LinkedIn and Instagram URLs with your real profiles.
2. Replace the example email and phone number in `contact.html`.
3. Add your real `resume.pdf` inside the `resume` folder.
4. Replace project demo/GitHub links with the actual URLs.

## GitHub Pages

Push the project to a GitHub repository, then open:

**Repository → Settings → Pages → Deploy from branch → main → /root → Save**

Your website will then be available through your GitHub Pages URL.
